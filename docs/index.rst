Bienvenido a la documentación del cliente de API de ContaFi.

.. toctree::
   :titlesonly:

   getting-started/index
   dev/index

ContaFi es un proyecto que tiene por objetivo gestionar procesos contables y financieros.

Aquí podrás encontrar la biblioteca escrita en lenguaje PHP para la integración con la API de ContaFi para emitir Boletas de Terceros Electrónicas (BTE), listar Remuneraciones, monitorear movimientos de dinero (Ingresos y Egresos), listar facturaciones (DTE, Compras y Ventas), y visualizar u observar Boletas de Honorarios (BHE).
